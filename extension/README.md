# Visualizing Code – Blöcke statt Syntax

Programmiere **Python, Java, JavaScript, C#, C++ und VBA** mit Scratch-ähnlichen Blöcken.

- `.blocks`-Dateien öffnen sich als Block-Editor. Der Code in der gewählten Sprache steht live daneben.
- Jede Code-Datei (`.py`, `.java`, `.js`, `.cs`, `.cpp`, `.bas`) lässt sich mit **„Als Blöcke öffnen“**
  (Symbol oben rechts im Editor) als Blöcke anzeigen und bearbeiten. Blöcke und Text bleiben synchron.
- **Start** führt das Programm in der eingebauten Konsole aus. **Im Terminal** startet den echten Code.
- **Code exportieren** übersetzt das Programm in eine der sechs Sprachen.

## Befehle

| Befehl | Wirkung |
|---|---|
| Visualizing Code: Neues Block-Programm | legt eine neue `.blocks`-Datei an |
| Visualizing Code: Als Blöcke öffnen | zeigt die aktuelle Code-Datei als Blöcke |
| Visualizing Code: In Block-Datei (.blocks) umwandeln | erzeugt aus einer Code-Datei eine `.blocks`-Datei |

## Hinweise

- Konstrukte ohne eigenen Block (z. B. Klassen, `try`/`catch`) werden als Code-Block übernommen.
- „Im Terminal“ braucht die jeweilige Sprache auf dem Rechner: `python3`, `node`, `java` (JDK 11+), `g++` oder `dotnet` (SDK 8).
